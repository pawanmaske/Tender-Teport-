# Tender Management Dashboard

A first UI prototype for the Tender Management Tool based on the provided User Manual v0.1.

## Run locally

Install Node.js, then:

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Notes

This version is a front-end prototype only. KPI values and tender rows are demo data. Database, authentication, permissions, APIs, notifications, audit history and Power BI integration will be added in later modules.
